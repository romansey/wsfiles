---
name: create-overview-docs
description: |
    This skill contains instructions on how to generate the documentation folder `overview-docs/`.
    The documentation has the purpose of providing a good overview of the project so that required exploration efforts of AI agents are significantly reduced in new sessions.
    Whenever an overview of the project is required, look for the contents of this folder first.
    If the folder does not exist, create it by following the instructions in this skill.
---

Take a look at the entire project and create markdown documentation files in `overview-docs/` that allow you to have a better understanding when performing more comprehensive changes on the project.
Document the project structure, domains (as in Domain Driven Design), interfaces to external systems, design/architectural patterns, additional concepts, and any other information that you find relevant.
Do not use the previous list of topics as a strict template, but use a structure that best fits the project.
